# showcase-design

The bytebent showcase page and design document. Both are single, self-contained HTML files:
open them straight from disk in any browser.

- `bytebent.html`: the showcase page. Built plugins with download links, the Creatures in
  progress, and the Lab concepts. No prices yet.
- `bytebent-design-document.html`: the design document. Brand, interface kit, product line,
  architecture, workflow, repos, business notes, roadmap and open questions. The version and
  date are in its menu bar.

Update both when a product's status changes.
